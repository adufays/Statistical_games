Everything you need is listed here. NumPy and the data are already loaded before each coding question, so you only have to replace the ??? and press RUN. The examples deliberately use different columns or values from the question, so they illustrate the syntax without giving away its answer.

SYNTAXWHAT IT DOESEXAMPLE FROM THIS EXERCISE
data['column']Selects one column from a pandas DataFrame. The result is a one-dimensional pandas Series. Column names must be inside quotes.storks['area_km2']
x.corr(y)Computes the Pearson correlation between two numerical columns of equal length. Here, x and y are columns selected from a table.storks['area_km2'].corr(storks['population_millions'])
data.plot.scatter(x='x', y='y')Draws a scatter plot from two columns in the same table. The arguments are column names, so they are written as strings. alpha controls point transparency.storks.plot.scatter(x='area_km2', y='population_millions', alpha=0.50)
data.head()Displays the first rows of a pandas DataFrame. With no number it displays five rows; a number inside the parentheses requests that many rows.daily.head(3)
x.mean()Computes the arithmetic mean of a numerical pandas Series or NumPy array. It does not work as a method of an ordinary Python list.storks['area_km2'].mean()
data['new'] = expressionCreates a new column in a pandas DataFrame. The expression must produce one value for every row.storks['pairs_per_birth'] = storks['stork_pairs'] / storks['births_thousands']
(x - 18)**2Subtracts a chosen reference value from every value of the numerical column x, then squares every result. Python powers use **, not ^.(daily['Temperature'] - 20)**2
print(f'{value:0.3f}')Formats one scalar value with three digits after the decimal point, then prints it.print(f"{storks['area_km2'].mean():0.3f}")
Names used above: data means a table such as storks or daily; x and y mean numerical columns selected from a table; value means one numerical result.
Prepared environment: import numpy as np and import pandas as pd. The table storks contains 17 countries; daily contains 1,096 days. Every coding question repeats exactly which table and columns are ready to use.
