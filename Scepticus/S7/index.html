Exercise VIII  ·  Statistical Models

Master Scepticus has always believed that a house is worth its square feet. 1,119 houses sold in Ames, Iowa, will test that belief. You will tell a correlation from a covariance, estimate a multiple regression, read two of its coefficients, predict the price of a house, and then check whether the regression deserves to be trusted. A logarithm will be called to the rescue.

PYTHON QUICK REFERENCE

Start your VS Code file with these lines. Put the Python file in the same folder as housing_continuous_no_outliers.xlsx, or give the full path to the Excel file. The examples below show the syntax on other columns than the ones the questions ask for.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm

data = pd.read_excel('housing_continuous_no_outliers.xlsx')
data.head()
SYNTAXWHAT IT DOESEXAMPLE
data['column'], data[['a', 'b']]Selects one column; or several columns, which gives a table.data[['GarageArea', 'years_since_remod']]
data.shape, x.mean(), x.min(), x.max()Number of rows and columns; average, smallest and largest value of a column.data['GarageArea'].mean()
data['new'] = ...Creates a new column in the table.data['garage_m2'] = 0.5 * data['GarageArea']
plt.scatter(x, y)Draws a scatter plot, x horizontally and y vertically. End with plt.show().plt.scatter(data['GarageArea'], data['years_since_remod'])
plt.axhline(0), plt.xlabel('text')Draws a horizontal line at height 0 (options: color='red', linestyle='--'); labels the horizontal axis. plt.ylabel labels the vertical axis.plt.axhline(0, color='red', linestyle='--')
x.corr(y)Pearson correlation between two columns.data['GarageArea'].corr(data['years_since_remod'])
data.corr()Correlation matrix of all the columns. Add ['column'] to keep the correlations of one column.data.corr()['GarageArea']
s.drop('label'), s.abs(), s.idxmax()For a series s: removes one entry; takes absolute values; gives the label of the largest value.data.corr()['GarageArea'].drop('GarageArea').abs().idxmax()
x.cov(y)Covariance between two columns.data['GarageArea'].cov(data['years_since_remod'])
np.log(x), np.exp(x)Natural logarithm and exponential. NumPy calls the logarithm np.log, not np.ln.np.log(data['GarageArea'] + 1)
sm.add_constant(X)Adds the column of ones, named const, needed to estimate an intercept.sm.add_constant(data[['GarageArea']])
sm.OLS(y, X).fit()Estimates a linear regression by ordinary least squares. The outcome comes first.model = sm.OLS(data['years_since_remod'], X).fit()
model.summary()Prints the regression table: coef, std err, t, P>|t|, R-squared.print(model.summary())
model.params, .pvalues, .tvalues, .rsquaredCoefficients, p-values, t-statistics and R². Add ['name'] to keep one entry.model.params['GarageArea']
model.resid, model.fittedvaluesResiduals, i.e., observed minus predicted outcome; and fitted values, i.e., the predicted outcome of each row.model.resid.mean()
model.predict(x_new)Prediction for new values. x_new needs the same columns as X, in the same order, the constant included.model.predict(pd.DataFrame([{'const': 1, 'GarageArea': 400}]))
